# pink-elevenlabs

Text-to-speech and voice transformation CLI using ElevenLabs API.

## Binaries

- `pink-elevenlabs-darwin-arm64` - macOS ARM64
- `pink-elevenlabs-linux-amd64` - Linux x64
- `pink-elevenlabs-windows-amd64.exe` - Windows x64

## Features

- Text-to-speech with customizable voice/model
- Voice transformation (change speaker identity)
- Opus 48kHz output format
- Streaming playback support

## Requirements

- `ELEVENLABS_API_KEY` environment variable
